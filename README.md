# AngadiMithra

## Smart Sales and Expense Management System for Local Retailers

### Project Overview

AngadiMithra is a web-based application designed to help local retailers manage their business operations efficiently. The system provides user authentication, sales tracking, expense management, and reporting features to support daily business activities.

The project is being developed using Python Flask as the backend framework and MySQL as the database management system.
